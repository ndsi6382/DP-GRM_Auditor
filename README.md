# Artefacts for "Practical Auditing of Differentially Private Graph Release Mechanisms: Methodology, Toolkit, and Case Study"

This repository contains the artefacts for "Practical Auditing of Differentially Prviate Graph Release Mechanisms: Methodology, Toolkit, and Case Study" by Nicholas D'Silva, Surya Nepal, and Salil S. Kanhere (2027). The article is available [here](). If you use this repository, please cite the following [work]():

```bibtex
insert_bibtex_here.
```

- `auditor.py` contains the open-source module developed in our work: a Python auditor for DP graph release mechanisms.
- `example_metrics.py` contains example function definitions of witness metrics for use in our auditor.
- `example_usage.py` provides an example usage on a toy graph dataset (Zachary's Karate Club) and the case study mechanism (PrivDPR).
- `documentation.pdf` contains full documentation of our auditor module.
- `requirements.txt` contains the Python dependencies for the module.
- `case_study/` contains an instantiation of our auditor on a real-world graph mechanism.
  - `case_study/Data` contains the datasets used and canary construction code.
  - `case_study/PrivDPR` contains the case study mechanism code (including migration reports).
  - The remaining `case_study/*` files contain helpers for running the case study and the obtained results.

Practitioners who wish to use the open-source module with their own mechanisms and datasets need only download `auditor.py` and install the dependencies listed in `requirements.txt`. The other top-level files provide guidance but are not required to use the module. The case study code is also not required.

Please note that due to file and repository size limitations, as well as usability considerations, the artefacts do not include all intermediate data for the case study. They do include the mechanism outputs for the toy dataset used in the example, along with all code, data sources, and output results. Intermediate results can be generated by using the provided code to reproduce the results, however note that doing so may require substantial disk space.
